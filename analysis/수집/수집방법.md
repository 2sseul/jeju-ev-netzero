# 데이터 수집 방법

수집에 실제로 사용한 스크립트입니다. 경로와 기간이 고정된 부분이 있어 참고용으로 두었습니다.

| 파일 | 내용 |
|---|---|
| `dl2.py`, `merge.py` | 공공데이터포털의 전력수요·발전량 과거 버전 내려받기, 병합, 단위 통일 |
| `smp_dl.py`, `smp_parse.py`, `smp_eda.py` | EPSIS 제주 SMP 월별 수집, 파싱, `smp_jeju.csv` 저장 |
| `smp_recent.py` | 2026-11-01 이후 SMP 수집 (`raw/smp_recent.csv`) |
| `fc_dl.py` | 제주 4개 지점 1·2일 전 예보 (2024-01 이후) |
| `land_fc_dl.py` | 전남·광주 4개 지점 2일 전 예보 |

`wx/fc.json`(2022-06~2024-06)과 `wx/era.json`은 Open-Meteo의 Previous Runs API와 Historical Weather API를 제주 4개 지점 좌표로 직접 호출해 저장했습니다. 호출 형식은 `fc_dl.py`와 같습니다.

`raw/land_curt_*.csv`는 공공데이터포털 15132422 데이터셋의 압축 파일에서 육지 파일을 꺼내 저장한 것입니다.

추가: `smp_land_dl.py`(육지 SMP), `ens_dl.py`(5개 예보 모델의 1·2·3일 전 예보).
